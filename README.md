readme instrucciones de ejecucion

Como ejecutarlo: 

Abrir netbeans y elegir File > open project > prueba5_prograII
Clic derecho en el proyecto > Clean and Build.
Clic derecho en el proyecto > Run (la clase principal es "Controlador.Main").

Instrucciones de uso: 

Escribir la ruta de la carpeta raíz, o presionar "Examinar".
(Opcional) Llenar filtros: extensión, tamaño mínimo y máximo en KB, fecha desde y hasta, y profundidad máxima (0 = ilimitada).
Usar los botones: Cargar árbol, Estadísticas, Buscar o Duplicados. Los recorridos corren en segundo plano; se puede detener con "Cancelar".
Las pestañas Gestión, Editor y Bitácora permiten crear, renombrar, copiar, mover y eliminar archivos, editar texto y ver el historial.

Archivos generados por el programa: 

- "bitacora.log": historial (fecha, hora, acción, ruta), en modo append.
- "config.txt": última ruta y filtros usados; se restauran al abrir.
Ambos se crean en la carpeta del proyecto.
